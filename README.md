## ✨ Características

- 📊 **Dashboard** con KPIs, área chart de ingresos semanales y próximas citas
- 📅 **Reservas** con filtros por estado y atención/cancelación en un click
- 🗓️ **Calendario mensual** con visualización de citas por día
- 💇 **Servicios** con precio, duración y código de color personalizable
- 👥 **Clientes** con sistema de fidelidad (Plata / Oro / Platino) y total gastado
- 🧑‍🤝‍🧑 **Equipo** con rating y estadísticas por estilista
- 📈 **Reportes** con gráficas de ingresos, distribución y ticket promedio
- 🌗 **Modo claro/oscuro** con paleta gradient morado-rosa
- 📥 **Exportación CSV** de reservas y clientes
- 🪄 **Wizard de reservas** en 3 pasos (servicio → hora → datos del cliente)

## 🛠️ Stack tecnológico

- **React 18** — hooks, `useMemo`, `useCallback`
- **Vite 5** — bundler con HMR
- **Recharts** — Area, Bar, Line, Pie
- **CSS-in-JS** — estilos inline con sistema de temas
- **GitHub Actions + GitHub Pages** — CI/CD

## 💻 Instalación local

```bash
git clone https://github.com/Juanmaya25/agendapro-bookings.git
cd agendapro-bookings
npm install
npm run dev
```

Abre [http://localhost:5173/agendapro-bookings/](http://localhost:5173/agendapro-bookings/).
